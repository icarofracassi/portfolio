Arnica F.Q.

CS50x Final Project — Full-Stack Football Tracker

Built for a group of friends who record their matches but had no way to keep statistics or revisit highlights. Tracks the full match lifecycle: attendance, roster assignment, substitutions, goals, assists — all stamped to video timestamps. Python Flask SQLite3 JavaScript Bootstrap 5 YouTube IFrame API

Engineering highlights
⚡
Materialized roster snapshots — pre-computed at every substitution boundary. Frontend does O(log n) binary search; fast enough for a 3-second poll cycle. Animates entries in green, exits in red.
🗃️
14-table schema with cascading FK relationships. player_stats_cache invalidates on roster change. arrived_at on presences prevents false bench-time attribution.
🔍
Global search joins across every participant in every event type — scorer, assister, both players in a sub, fouled player, and notes — with GROUP BY deduplication.
